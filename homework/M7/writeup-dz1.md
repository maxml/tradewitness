## Какие сущности уводят в локалку

- PII в тексте (имя/email/телефон/карта; ru/uk — см. acceptance в PLAN §4.2).
- Любые user-owned данные (мои трейды / капитал / заметки / стратегии) — потому что
  ответ тула приватный и не должен уехать в облако (PLAN §2.2).
- Ambiguous-запросы — по умолчанию local (cloud не fallback).

## Почему роутеру не нужен GPU

Решение о маршруте — это лёгкий PII-детект (Presidio, CPU) + детерминированные правила
в TS. Решение о маршруте всегда дешевле работы, которую оно маршрутизирует. GPU нужен
максимум модели-ответчику (Ollama), и то для личного прогона хватает CPU+iGPU/4GB.

## Подвох приватности (адресован архитектурно)

Роутер смотрит не только PII в тексте, но и чувствительность данных, которые тронут тулы
(PLAN §2.2): cloud в DZ1 вообще не имеет user-owned тулов; приватная история не попадает
в cloud-контекст; sensitivity эскалируется по ответу. Глубже — внешний `THEORY-privacy-routing.md`.
